## 経験点配布

本シナリオで配布される経験点は以下の通りである。

| 項目 | 経験点 |
| :--- | ---: |
| セッションに最後まで参加した | 1点 |
| 背理天賦を撃破した | 8点 |
| プレゼントを交換した | 2点 |
| エネミーのEロイス・Dロイスによる経験点 | 7点 |
| 最終侵蝕率による経験点 | 0~5点 |
| Sロイスがタイタスにならなかった | 5点 |
| よいロールプレイをした | 1点 |
| 他のプレイヤーを助けるような発言や行動を行った | 1点 |
| セッションの進行を助けた | 1点 |
| 場所の手配、提供、連絡や参加者のスケジュール調整などを行った | 1点 |

プレイヤーが得た経験点の合計値を3で割り、「場所の手配、提供、連絡や参加者のスケジュール調整などを行った」かどうかで1点を加え、GMの経験点とせよ。

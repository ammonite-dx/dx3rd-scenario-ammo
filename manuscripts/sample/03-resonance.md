# 共鳴の中心

- **日時**: 秋の夜
- **場所**: 旧バスターミナル地下・音響実験室
- **シーンプレイヤー**: PC全員

## 解説

実験室で星野キリと対話し、灰灯をどう扱うか決めるシーン。キリは悪意だけで行動しているわけではないが、装置の力を止めるにはPCたちの決断が必要になる。

## 描写

実験室の中央には、煤けたランタンに似た装置が吊られている。内部の光は明るくない。それでも見つめていると、自分が忘れたはずの声が、耳の奥からゆっくり戻ってくる。

:::dialogue 星野キリ

「灰灯は、失われる前の声を残すために作りました。私が守りたかったのは、弟の最後の言葉です。」

（PCが装置を止める理由を問うた場合）「分かっています。今の灰灯は、誰かの記憶を奪わなければ動けない。けれど、止めれば弟の声も消えてしまう。」
:::

:::dialogue 通信越しのケイ

「キリ、聞こえているなら装置から離れてください。灰灯はもう、あなたの記憶だけを保存している状態ではありません。」

（キリが返事をしない場合）「PCたち、装置の脇に手動の遮断器があります。使うかどうかは、現地の判断に任せます。」
:::

:::e-lois 《静寂の贈与》

[対象] 実験室にいるPCと一般人
[条件] 灰灯が、聞き手の記憶から声を切り取ろうとした時

このEロイスは、失われた声を一時的に鮮明にする代わりに、別の声をひとつ薄れさせる。シーン中、装置のそばにいる者が自分の大切な記憶を口にした場合、その記憶は灰灯に固定される。Eロイスの処理はこの場面の演出として扱い、戦闘の終了条件や敵データを変更しない。
:::

:::roleplay 灰灯の前の決断

[対象] PC全員
[条件] キリの事情と灰灯の危険性を知った後

PCたちは、キリに残したい声を尋ねるか、遮断器へ向かうかを話し合う。キリは説得を受けてもすぐには装置を手放せないため、最後はPCたちが行動を選ぶ。
:::

:::choice 灰灯をどう扱うか

[対象] 灰灯の記憶装置
[条件] PCたちがキリの記憶を聞き終えた時
[分岐] 選んだ方法に応じて、クライマックス開始時の状況を変える

1. **記録媒体を抜く** — 灰灯を止め、失われた声をこれ以上増やさない。キリは戦闘開始時に動けず、実験体だけがPCたちの前に残る。
2. **キリに声を返す** — キリ自身に最後の言葉を言わせ、装置を手放すよう促す。キリは戦闘開始時にPC側へ避難し、実験体の最初の行動はPCの後になる。

どちらを選んでも実験体の共鳴は止まらない。[灰灯の実験体との決戦](04-climax.md)へ進む。
:::

## 結末

PCたちが灰灯の扱いを決め、実験室から実験体の気配が現れたらシーン終了。

# 灰色信号のテストラン {.scene-title}

これはA5 MVPの変換経路を確認するための動作確認用ダミーシナリオである。既存の `gift` 本文は複製していない。まずは[作戦概要](#scene-brief)を確認し、最後に[観測ログ](#signal-log)へ進む。

## Scene Brief

市街地の観測区画で、オーヴァード反応を示す灰色の信号が一度だけ記録された。PCたちは閉鎖前の研究棟へ入り、信号の発信源と残された記憶媒体を確保する。

- PCは少なくとも1人の調査担当者を含む。
- GMは信号の正体を、戦闘と情報開示の両方で示す。
- 目的は記憶媒体の確保であり、敵の全滅は必須ではない。

:::dialogue{title="通信士ユナ"}

「灰色信号は、廃棄された観測端末から出ています。まだ誰かが、向こう側で応答しているみたいです」
:::

:::roleplay{title="崩れた観測室"}

プレイヤーは観測室の様子を自由に描写する。端末の明滅、床に残った薬莢、窓の外の静けさなど、調査したい対象を一つ選ぶ。
:::

:::choice{title="信号への接近"}

PCたちは信号を追う方法を相談する。

1. 端末を直接調べ、発信源を特定する。
2. 窓から外を観察し、周囲の動線を確認する。
3. いったん退路を確保してから、記憶媒体を探す。
:::

:::check{title="ノイズの発信源を探す" skill="〈知覚〉" difficulty=8 mandatory=true}

成功した場合、端末の下に隠された記憶媒体を発見する。失敗した場合も発信源は分かるが、実験体が先にPCたちへ接近する。
:::

:::info{title="GM向け：観測ログの開示"}

| 開示条件 | 判明する情報 |
| --- | --- |
| 端末を調べる | 信号は三分間隔で短く応答している。 |
| 記憶媒体を確保する | 研究棟の奥で、記録者が自分を封じた経緯が分かる。 |
| 戦闘後に再確認する | 信号はPCの侵蝕率に反応していたと判明する。 |
:::

:::e-lois{title="《記憶の残響》"}

このEロイスは、記録者の恐怖が観測機器へ残留したものだ。記憶媒体を破壊しない限り、信号は別の端末へ移り続ける。
:::

:::battle{title="実験体との接触"}

### 敵データ

| 敵 | 数 | 行動 |
| --- | ---: | --- |
| 灰色の実験体 | 1 | 記憶媒体を奪い、退路を塞ぐ。 |
| 反応性ドローン | 2 | 端末の周囲を飛び、侵蝕を促す。 |

### 戦闘終了条件

実験体が戦闘不能になるか、PCが記憶媒体を確保して観測室を離れれば終了する。
:::

:::combo{title="《薄明の一閃》"}

| 項目 | 値 |
| --- | --- |
| タイミング | メジャーアクション |
| 対象 | 単体 |
| 射程 | 視界 |
| 判定 | 8dx7+4 |
| 効果 | 光刃で攻撃し、命中時に対象の移動を1段階遅らせる。 |

PCが記憶媒体を守るために使う、動作確認用の代表コンボである。
:::

## Signal Log

観測室を離れると、灰色信号は一度だけ明滅して消える。PCたちは記憶媒体を持ち帰り、次の調査へ向かう。

### Debrief

- 成功時は、信号の発信源とEロイスの関係を記録する。
- 失敗時は、実験体の断片的な記憶を次のシーンの手掛かりにする。
- どちらの場合も、サンプル原稿の確認結果を受け入れ記録へ残す。
